# Tic-Tac-Toe

A simple Tic-Tac-Toe game built with React.js.

## Live Demo
Play the game here: [Tic-Tac-Toe](https://tic-9b172t01y-prasha111s-projects.vercel.app)

## Features
- Two-player gameplay (X vs O)
- Click on a box to make a move
- Alternating turns
- Displays the current player
- Responsive grid layout

## Installation
To run the project locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/prasha111s/tic-tac-toe.git
   cd tic-tac-toe
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm start
   ```

4. Open the browser and go to:
   ```sh
   http://localhost:3000
   ```

## How to Play
- Click on an empty box to place an 'X' or 'O'.
- Players take turns.
- The first player to align three marks in a row, column, or diagonal wins.
- If all boxes are filled without a winner, it's a draw.
